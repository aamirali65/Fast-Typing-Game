# Fast-Typing-Game

A browser typing-speed test: type the given text as fast and as accurately as you can, and the page reports how you did.

## How it works

The text to type is displayed, keystrokes are compared against it as you go, and a timer starts with your first input so the final result reflects typing speed rather than reading time.

## Files

```
index.html   the prompt text, input area and results panel
script.js    timer, character comparison and scoring
style.css    layout and feedback styling
```

## Running

Open `index.html` in a browser — no dependencies.

## Notes

Vanilla JS practice, focused on input events and timing. Everything is computed client-side from the text the page ships with.
